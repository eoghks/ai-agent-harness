# 위키 골격 생성

위키 경로: `<사용자 홈>\wiki` (예: C:\Users\daehwan\wiki — 머신마다 홈 디렉토리 기준)

새 머신/새 환경에서 위키(옵시디언 vault) 골격을 만든다. /todo·/work·/worklog·/reports 스킬이
이 구조를 전제로 동작하므로, 위키가 없는 머신에서 먼저 한 번 실행한다.

## 멱등 규칙 (필수)

- **이미 있는 파일·폴더는 절대 건드리지 않는다.** 각 항목을 만들기 전에 존재 여부를 확인하고,
  있으면 그대로 두고 "이미 존재 — 건너뜀"으로 보고한다. 기존 내용을 덮어쓰지 않는다.
- 새로 만든 항목만 "생성"으로 보고한다. 반복 실행해도 결과가 같아야 한다.
- 옵시디언 설정(`.obsidian\`)은 옵시디언이 vault를 열 때 자체 생성하므로 만들지 않는다.
- 위키는 git을 사용하지 않는다 — 파일 생성만 하고 어떤 git 명령도 실행하지 않는다.

## 생성 대상

`<사용자 홈>\wiki\` 아래에 다음을 멱등 생성한다.

- `작업로그\` — 폴더만. 월별 `YYYY-MM.md`가 /work·/worklog로 쌓이는 곳이다(초기엔 빈 폴더).
- `에이전트보고\` — 폴더 + `_index.md`(테이블 헤더만).
- `TODO.md` — 할 일 목록(/todo가 관리). 초기엔 제목 헤더와 섹션만.
- `README.md` — vault 안내 + 각 폴더/파일 용도·형식.

## 초기 파일 템플릿

### `에이전트보고\_index.md`

```markdown
# 에이전트 보고서 인덱스

> 백그라운드 서브에이전트 완료 보고서 전문 보관소. 미열람 우선 정렬.
> 이 인덱스는 캐시다 — 어긋나면 각 보고서 frontmatter를 Grep으로 스캔해 재생성한다.

| 읽음 | 일시 | 에이전트 | 작업 | 상태 | 파일 |
|---|---|---|---|---|---|
```

### `TODO.md`

```markdown
# TODO

## 인박스

## 진행 중

## 완료

<!-- 완료 항목은 최근 20개만 유지 — 오래된 것은 /todo 정리 시 삭제 -->
```

### `README.md`

```markdown
# 개인 작업 위키

> 옵시디언 vault로 열어서 보는 것을 권장 (Open folder as vault → 이 폴더 선택)
> Claude Code 하네스가 이 폴더를 직접 읽고 쓴다.
> 이 vault 구조는 하네스 `/wiki-init`이 단일 출처다.

## 구조

| 위치 | 용도 | 갱신 주체 |
|------|------|----------|
| `TODO.md` | 할 일 인박스·진행 중·완료 | `/todo` 스킬 |
| `작업로그/YYYY-MM.md` | 월별 작업 기록 | `/work` 완료 시 자동, `/worklog`로 조회 |
| `에이전트보고/_index.md` | 에이전트 보고서 인덱스(캐시) | `/work`·`/reports` 스킬 |
| `에이전트보고/<날짜>_<작업>.md` | 에이전트 보고서 전문 | 서브에이전트 완료 시 |
| `프로젝트/<이름>.md` | 프로젝트별 노트·결정 사항 | 수동 + 필요시 Claude |
| `노트/<주제>.md` | 기술 노트, 트러블슈팅 | 수동 + 필요시 Claude |

## 형식 요약

- **작업로그 항목** (`작업로그/YYYY-MM.md`, 최신이 위):
  ```
  ### YYYY-MM-DD — <작업 제목>
  - 프로젝트: <경로 또는 이름> / 브랜치: <브랜치명>
  - 내용: 핵심 변경 1~2줄
  - 결과: 빌드·테스트·리뷰 요약 1줄
  - 보고서: <에이전트보고/ 파일 경로들>
  ```
- **에이전트 보고서 frontmatter**: title, agent, date, project, status, read, summary.
  frontmatter 아래에 보고 전문을 둔다.
- **TODO 항목**: `- [ ] 내용 (등록: YYYY-MM-DD)`, 완료 시 `- [x] 내용 (등록: ..., 완료: YYYY-MM-DD)`.

## 동기화

git 사용 안 함 — 옵시디언 로컬 vault로만 사용한다.
(집 PC와 동기화가 필요해지면 그때 옵시디언 동기화 수단을 따로 결정)
```

## 보고

생성한 항목과 이미 존재해 건너뛴 항목을 구분해 목록으로 보고한다.
모두 이미 있으면 "위키 골격이 이미 구성돼 있습니다 — 변경 없음"으로 보고한다.
