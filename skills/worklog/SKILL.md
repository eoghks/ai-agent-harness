# 작업로그 조회

위키 경로: `<사용자 홈>\wiki` (예: C:\Users\daehwan\wiki — 머신마다 홈 디렉토리 기준)
대상: `wiki\작업로그\YYYY-MM.md` (월별 파일, 항목은 `### YYYY-MM-DD — 제목` 형식, 최신이 위)

작업로그는 /work 완료 시 자동 기록된다. 이 스킬은 그 기록을 **읽기만** 한다.

## 동작

- **`/worklog`** (인수 없음) 또는 "최근 작업 뭐 했지?" → 가장 최근 월 파일을 찾아
  상위 10개 항목을 요약 표시한다. 각 항목의 제목(`### ...`)과 내용·결과 1줄을 보여준다.
- **`/worklog YYYY-MM`** (예: `/worklog 2026-06`) 또는 "지난달 작업로그" → 해당 월 파일 전체를
  표시한다. 파일이 없으면 "해당 월 로그 없음"으로 안내한다.
- **`/worklog <키워드>`** 또는 "결재선 관련 작업 찾아줘" → 전체 작업로그 파일에서 키워드를
  Grep으로 검색해, 매칭된 항목(`### ` 단위)을 해당 월과 함께 표시한다.
  매칭이 없으면 "해당 키워드 항목 없음"으로 안내한다.

## 규칙

- **읽기 전용**이다 — 작업로그 파일을 수정하지 않는다. 기록은 /work 7단계가 담당한다.
- 위키 폴더(또는 `작업로그\` 폴더)가 없으면 "/wiki-init으로 먼저 구성하세요"로 안내하고 중단한다.
- 가장 최근 월은 `작업로그\` 안의 `YYYY-MM.md` 파일명을 정렬해 가장 큰 것으로 판단한다.
- 위키는 git을 사용하지 않는다 — 어떤 git 명령도 실행하지 않는다.
