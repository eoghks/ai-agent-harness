# 버그 분석

$ARGUMENTS 로 받은 증상을 분석한다.

1. 증상 정보가 부족하면(언제부터, 어떤 입력, 에러 메시지, 재현 조건) 먼저 사용자에게 묻는다.
2. analyzer 에이전트에 증상·재현 정보를 자기완결적으로 정리해 위임한다
   (run_in_background로 실행하고 즉시 턴을 종료 — 메인 세션은 사용자가 계속 쓸 수 있게 한다).
3. analyzer 보고 전문은 위키 보고서로 저장되므로(전역 CLAUDE.md "에이전트 보고서 위키 저장" 참조),
   메인 세션은 한 줄 요약 + 보고서 경로로만 보고한다(`/reports`로 열람).
   단 needs-input(원인 미확정으로 추가 정보 필요)이거나 확정 원인이 차단성이면
   핵심 내용(근본 원인·영향 범위·수정 방안)을 즉시 채팅에 표출한다.
4. 사용자가 수정 방안을 승인하면 /work 사이클로 이어간다 —
   분석 보고를 작업 명세서의 재료로 사용한다.
