# 할 일 관리

위키 경로: `<사용자 홈>\wiki` (예: C:\Users\daehwan\wiki — 머신마다 홈 디렉토리 기준)
대상 파일: `wiki\TODO.md`

## 동작

- **`/todo`** (인수 없음) 또는 "뭐 해야 하지?" → 인박스·진행 중 항목을 번호 붙여 보여준다.
- **`/todo <짧은 내용>`** 또는 "~~ 할 일로 등록해줘" → 인박스에 추가:
  `- [ ] 내용 (등록: YYYY-MM-DD)`
- **`/todo done <번호>`** 또는 "2번 끝났어" → 완료 섹션으로 이동, 완료일 기록:
  `- [x] 내용 (등록: ..., 완료: YYYY-MM-DD)` — 완료 섹션은 최근 20개만 유지.

## 요청사항 접수 (노션 등 외부 출처)

**파일이 오면 (PDF·md·txt 경로, 드래그앤드롭 포함):**
1. Read로 파일을 읽는다 — 노션 "PDF로 내보내기" 파일 포함.
2. 요청사항이 여러 건이면 **각각 별도 할 일로 분리**해 인박스에 추가한다.
3. 상세 내용(배경, 조건, 담당자, 기한)은 `wiki\노트\<요청명>.md`로 저장하고
   할 일 항목에 `→ [[요청명]]` 옵시디언 링크를 단다. 기한이 있으면 할 일에 `(기한: ...)` 표기.
4. 결과를 보고한다: 등록된 할 일 목록 + 생성된 노트.

**긴 텍스트 복붙이 오면:** 파일과 동일하게 처리한다 (요약 → 할 일, 상세 → 노트).

## 규칙

- TODO.md의 섹션 구조(인박스/진행 중/완료)를 유지한다.
- 위키는 git을 사용하지 않는다 — 파일 수정만 하고 어떤 git 명령도 실행하지 않는다.
- 위키 폴더가 없으면 경로를 보고하고 중단한다 (임의 위치에 생성 금지).
- 요청 내용이 모호해도 일단 등록한다 — 등록이 우선, 정제는 나중에.
